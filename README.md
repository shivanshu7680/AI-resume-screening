# 🤖 AI Resume Screening System

An AI-powered Resume Screening System built using **Flask**, **Machine Learning**, and **Natural Language Processing (NLP)**. This application analyzes resumes, calculates ATS compatibility, predicts job roles, extracts skills, matches resumes with Job Descriptions, and provides personalized improvement suggestions.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/sharadverma6306/AI-Resume-Screening-System.git
```

```bash
cd AI-Resume-Screening-System
```

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate the Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```

## 📊 AI Modules

### ⭐ ATS Score

Calculates resume compatibility using weighted ATS parameters.

### 🤖 Resume Classification

Predicts the most suitable job category using Machine Learning.

### 💡 Skill Extraction

Automatically extracts technical skills from uploaded resumes.

### 📄 JD Matching

Compares the uploaded resume with the provided Job Description.

### 🔍 Missing Skills Detection

Identifies important skills and keywords missing from the resume.

### 📈 AI Suggestions

Provides personalized recommendations to improve resume quality.
